# InsurePredict

Health Insurance Cost Predictor made using React, FastAPI and Machine Learning.

## About

This project predicts the approximate health insurance cost based on some basic details like:

- Age
- Sex
- BMI
- Children
- Smoker
- Region

The project was created from scratch as a learning/project work.

## Technologies Used

### Frontend
- React
- Vite
- CSS

### Backend
- FastAPI
- Python

### Machine Learning
- Pandas
- NumPy
- Scikit-learn
